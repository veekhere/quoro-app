# Quoro

macOS menu bar app that shows inspirational quotes.

## Requirements

- macOS 14 Sonoma or later
- Xcode 15 or later

## Installation

1. Open `Quoro.xcodeproj` in Xcode.
2. Select the **Quoro** scheme and your Mac as the run destination.
3. Press **Run** (`⌘R`).

Quoro appears in the menu bar as a quote-bubble icon. Click it for a quote; use **Next quote** or **Quit Quoro** from the menu.
